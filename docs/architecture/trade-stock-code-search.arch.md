# 投资股票代码/名称搜索与清仓删除设计

日期：2026-08-26

## 设计选择

- 观察列表使用代码/名称搜索纯函数；持仓下拉保留仅代码搜索纯函数，避免名称搜索扩大建仓选择器本次范围。
- 现价单元格复用同一无副作用距离函数，分别传入乐观、中枢、悲观目标价；只增加派生展示，不新增状态、持久化或网络副作用。
- 搜索状态停留在 React 组件内，不扩展领域 schema、IPC 或 SQLite 表结构。
- 观察列表的数据管道为：完整观察列表 → 代码搜索 → 状态/标签筛选 → 分页；行情轮询与持仓引用仍读取完整列表。
- 持仓选择器采用“弹层容器 + 搜索输入 + listbox”结构，避免把文本框直接放入 `listbox`。
- 已清仓删除复用 `trade.positions` 的单资源替换；按稳定 ID 过滤一次即可保持当前/历史数据的一致性。

## 数据流

```text
观察代码/名称搜索词 ─┐
状态筛选 ───┼→ 交集筛选 → 每页 10 条 → 观察列表视图
标签筛选 ───┘

下拉搜索词 → 代码匹配 → listbox 候选 → 稳定 watchlistId → 新持仓

已清仓删除 → 按 position.id 过滤 trade.positions → typed IPC → SQLite
```

## 实施计划

1. 添加代码/名称搜索和现价距三档目标价计算纯函数及边界测试。
2. 接入观察列表搜索、指标展示和分页复位。
3. 扩展持仓自绘下拉的搜索、空状态和键盘候选范围。
4. 为已清仓行接入稳定 ID 删除动作并更新表格布局。
5. 同步现状需求、入口 Map、总规格和进度，运行完整校验。
