# 物品列表管理规格

> 状态：已确认（依据用户 2026-08-19 指令）  
> 范围：`Items` 单模块小功能

## 目标

- 物品模块主内容使用列表展示，不再用卡片网格展示普通物品。
- 食物继续使用独立完整清单，保留到期日和 Crimson/Amber 预警。
- 普通物品和食物都能在当前行编辑、取消和删除。

## 交互与校验

1. 普通物品列表展示名称、分类、位置、详情和操作；食物列表展示名称、位置、到期日、状态和操作。
2. “编辑”在原行打开表单，不跳转页面、不使用 `prompt()`；“取消”或 `Escape` 放弃草稿并恢复展示态。
3. 普通物品可修改名称、非食物分类、位置和详情；食物可修改名称、位置和到期日。食物与普通物品分属既有资源，编辑时不跨资源转换分类。
   - 兼容既有 `items.items` schema 中可能存在的 `type: 食物` 记录：读取时不丢弃该记录，但普通物品编辑器不提供新增的跨资源转换入口。
4. 名称和位置 trim 后必须为 1–200 字，详情最多 500 字；食物到期日必须是 `YYYY-MM-DD`。
5. 保存后仍使用原稳定 ID，并即时重算食物预警；非法输入保留编辑态并在当前行显示错误。
6. 删除按稳定 ID 仅移除目标记录，不级联修改其他模块；空列表显示明确空状态。

## 副作用

- `Items`：读取并通过 `setItems` / `setFoods` 替换 `items.items`、`items.foods`，由 `useDomainResource` 经 typed IPC 持久化到 SQLite；同时更新页面级状态消息。
- `ItemRow` / `FoodRow`：只更新组件内编辑草稿和错误状态；保存、删除通过回调交给 `Items`，自身不直接访问 IPC、存储或网络。
- 编辑、取消和输入校验不写持久化资源；保存和删除各触发一次对应资源替换。
- 本功能不发起网络请求、不访问剪贴板、不创建通知、不修改其他领域资源。

## 验收

- 普通物品以列表呈现，食物完整清单仍可见且预警样式不回退。
- 普通物品与食物均覆盖编辑保存、取消恢复和删除。
- 自动测试覆盖列表结构、稳定 ID 更新语义、校验错误、删除及食物到期状态重算。
- 样式优先复用全局五列列表、行内编辑和操作按钮规则；生产 CSS 必须继续满足发布审计的 25 KiB 上限。
