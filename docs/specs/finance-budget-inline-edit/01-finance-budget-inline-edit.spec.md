# 财务月度预算原地编辑规格

> 状态：已确认（依据用户 2026-08-29 指令）  
> 范围：财务模块月度预算卡片

## 目标

- 用户点击月度预算金额后，在原卡片、原位置编辑预算，不使用 `prompt()` 或跳转页面。
- 保存后立即重算预算消费比例与预警，并在应用重启后保留。

## 交互与校验

1. 展示态继续显示“已用金额 / 月度预算金额”，预算金额是“修改月度预算”按钮。
2. 点击后，预算金额位置切换为金额输入框、“保存”和“取消”；输入框自动使用当前预算作为草稿。
3. `Escape` 或“取消”放弃草稿并恢复展示态，不写持久化资源。
4. 保存只接受大于 0、最多两位小数的十进制金额；拒绝负数、0、指数、千分位、超过两位小数和非安全整数。
5. 非法输入保留编辑态并显示页面状态消息；合法保存退出编辑态并提示“月度预算已更新”。

## 副作用

- 打开编辑、修改草稿、取消和输入校验仅更新 React 局部状态。
- 合法保存调用一次 `setBudgetCents`，由 `useDomainResource` 经 typed IPC 以新 request ID 幂等替换 `finance.budgetCents` 和 SQLite `domain_value`。
- 保存后 `budgetProgress` 纯函数随新预算重新派生百分比与告警；不修改已用金额、交易、待评估队列或长期目标。
- 本功能不访问网络、剪贴板、文件系统或通知。

## 验收

- 将 ¥3,000.00 修改为 ¥4,000.00 后，卡片显示新预算且消费比例即时变化。
- 取消或按 `Escape` 后仍显示原预算。
- 非法金额不保存，并显示明确错误。
- 类型、组件、静态规格、Rust、生产构建和发布审计通过。
