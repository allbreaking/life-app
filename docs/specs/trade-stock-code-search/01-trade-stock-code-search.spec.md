# 投资股票代码/名称搜索与清仓记录删除规格

日期：2026-08-26  
阶段：DEV

## 目标

降低观察标的和建仓标的的定位成本，并允许用户清理不再需要的已清仓历史。

## 功能规格

1. 观察列表提供股票代码或名称搜索框。
   - 搜索词去除首尾空格后，以代码子串或名称子串匹配；名称中的拉丁字母忽略大小写。
   - 空搜索词匹配全部标的。
   - 代码搜索、价格状态和标签筛选取交集，随后再执行每页 10 条分页。
   - 搜索词变化时回到第一页；搜索不改变行情刷新、持仓来源或引用保护使用的完整观察列表。
2. 观察列表“现价”单元格同时展示“距乐观”“距中枢”“距悲观”三个百分比。
   - 统一公式：`(对应目标价 / 现价 - 1) × 100%`。
   - 展示顺序为距乐观、距中枢、距悲观，三项均位于现价下方。
   - 正数带 `+`，负数保留 `-`，展示两位小数。
   - 非有限或非正现价显示 `—`，不得影响该行其他字段。
3. 持仓管理的观察标的下拉层提供股票代码搜索框。
   - 使用与观察列表相同的去空白和子串匹配规则。
   - 搜索只缩小当前候选项，不修改已选择的稳定观察标的 ID。
   - 无匹配项时展示明确空状态；关闭下拉后清空临时搜索词。
4. 已清仓 Tab 的每条记录提供“删除”操作。
   - 按稳定持仓 ID 从 `trade.positions` 原子资源中移除对应记录。
   - 不修改其他当前持仓或清仓记录，不级联删除观察标的。
   - 删除后立即更新界面，并通过既有领域资源链路持久化。

## 函数与副作用

- `searchWatchlist(items, query)`：观察列表代码/名称搜索纯函数；不修改输入，不读写存储，不发网络请求。
- `searchWatchlistByCode(items, query)`：持仓下拉代码搜索纯函数；不修改输入，不读写存储，不发网络请求。
- `centralTargetDistanceFromCurrentPercent(current, target)`：纯函数；传入任一档目标价时返回该目标价相对现价的派生百分比或 `NaN`。
- `Trade` 搜索状态：仅 React 瞬时状态；不持久化。
- `WatchSelect` 搜索、展开和选择：仅修改组件瞬时状态；提交时仍通过父表单传递稳定 `watchlistId`。
- `deletePosition(positionId, kind)`：更新 `trade.positions`，触发 typed IPC 与 SQLite 持久化；不修改 `trade.watchlist`，不发网络请求。

## 安全、幂等与异常边界

- 搜索词仅参与字符串比较并由 React 文本节点展示，不进入 HTML、SQL、shell 或网络请求。
- 删除使用已有稳定 ID，不接受索引；重复触发不会删除其他记录。
- 无结果、空列表和选中项暂时不在搜索结果中均不得导致表单提交错误或运行时异常。

## 验收标准

- 观察列表可按部分股票代码或名称搜索，并与现有筛选、标签和分页正确组合。
- 每个非编辑态观察标的在现价下方显示按指定公式计算的距乐观、距中枢、距悲观百分比。
- 建仓下拉可按部分股票代码收窄候选项，清空搜索后恢复完整列表。
- 已清仓记录可删除；当前持仓删除和观察标的引用保护仍按原规则工作。
- 纯函数测试、组件回归测试、类型检查、静态规格校验和生产构建通过。
