# 原型冻结与开发基线

## 目标产品

Life-OS 是 macOS 本地优先的个人认知运行系统。正式版本以桌面应用交付，数据默认只保存在本机，不依赖账号或云端服务。

## 原型冻结物

- 产品需求：`Life-OS_PRD_v3.md`
- 交互原型：`life_os_prototype.html`
- 原型补充规格：`docs/spec.md`

原型只负责确认信息架构和交互，不直接作为生产代码继续扩展。正式开发可以复用设计 token、文案和业务规则，不复用原型中的 DOM 快照持久化方式。

## 正式 MVP 范围

- 九大模块与全局快捷录入。
- SQLite 本地持久化及迁移。
- 工作任务、日程排期和完成状态双向同步。
- 生活日程固定模板。
- 财务预算/时间进度预警和非必要支出队列。
- 物品位置、食物完整清单及保质期预警。
- 社交人物名片和重要日期。
- 投资观察列表、持仓外键约束和每日复盘。
- 学习领域列表与领域工作区。
- 本地备份与恢复的最低可用能力。

## MVP 非目标

- 多用户、云同步、Web 公网版。
- 自动交易、投资建议或行情分析。
- OCR、AI 自动分类和复杂自然语言解析。
- iOS/Windows 客户端。
- 插件市场和多人协作。

## 冻结原则

- 快捷录入不是模块唯一入口。
- 日程是唯一拥有具体排期权限的模块。
- 生活日程是只读投影，不能在日/周/月视图修改。
- 学习外层只管理领域，任务与里程碑在领域工作区内管理。
- 所有用户数据可编辑；删除操作需要明确目标并可恢复或确认。
