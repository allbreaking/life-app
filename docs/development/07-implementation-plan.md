# 开发实施计划

## P0 工程骨架

- 初始化 Tauri + React + TypeScript。
- 建立设计 token、路由、错误边界、日志和测试框架。
- 建立 SQLite、迁移、repository 与 typed IPC。

交付：空壳可运行、数据库可迁移、CI 门禁可执行。

### P0 模块运行态持久化桥

- 以 `09-module-state-persistence.md` 定义的 typed IPC 和 SQLite 仓库替换冻结原型的组件内业务状态。
- 该桥只承接原型迁移数据；既有规范化领域表及其约束不被 JSON 状态替代。
- 后续 P1–P5 逐模块切换至细粒度领域命令，并通过前进迁移导入对应状态键。

## P1 共享任务与日程基础设施

状态：已完成领域资源命令迁移与旧状态前进导入。

- 统一 task 模型和来源引用。
- 待排期池、日/周/月查询。
- 连续时间画布、排期、重排、退回池。
- 生活日程模板投影。

交付：工作/学习产生的任务可完整走通排期闭环。

## P2 工作、总览、人生地图

状态：已完成领域资源命令迁移与旧状态前进导入。

- 四象限、Top 3、EOD 联动。
- 总览聚合与预警入口。
- 原则、北极星和演进日志。

## P3 财务与物品

状态：已完成领域资源命令迁移与旧状态前进导入。

- 预算、必要/非必要支出、订阅。
- 位置、食物、使用时期和维护预警。
- 财务与物品规则的显式联动。

## P4 社交与学习

状态：已完成领域资源命令迁移与旧状态前进导入。

- 人物名片、互动、重要日期。
- 领域列表、整页工作区、里程碑和学习任务。

## P5 投资

状态：已完成领域资源命令迁移与旧状态前进导入。

- 观察列表、持仓外键、交易明细和每日复盘。
- 行情 adapter 先提供手动价格，再接受控轮询。

## P6 桌面能力与发布

- 菜单栏、系统快捷键、通知、备份恢复。
- 性能、可访问性、签名和发布验收。

### P6-B4 实施计划

1. 将 SQLite 连接收敛为领域资源、通知与备份服务共享的互斥连接。
2. 实现应用内快照创建、列表、候选校验、恢复前回滚快照和失败回滚。
3. 增加 typed IPC 与“数据保护”界面，保留浏览器预览降级。
4. 覆盖路径输入、完整性/schema 校验、成功恢复、失败回滚和确认交互测试。
5. 更新追踪矩阵与进度，执行 TypeScript、组件、静态规格、Rust 和生产构建校验。

### P6-C1 实施计划

1. 冻结首屏 JavaScript、CSS 与 gzip 总量预算，并定义版本/CSP/capability/icon 审计规则。
2. 增加无网络依赖的发布审计脚本和 `release:verify`、`desktop:bundle` 命令。
3. 配置跨平台 bundle 图标，验证生产 Web 构建和当前平台未签名桌面 bundle。
4. 更新测试计划、追踪矩阵和进度；签名、公证、安装权限与视觉回归保留为真实发布环境门禁。

### P6 菜单栏日程单源重构

1. 抽取共享已排期任务 schema，加入向后兼容的 `completed=false` 字段，并由应用壳层统一持有资源。
2. 今日总览按本地日期从 `schedule.scheduled` 派生并按时间排序；点击按稳定 ID 更新同一任务。
3. typed IPC 将下一条未完成日程同步到 macOS 菜单栏；菜单完成事件只回传当前稳定任务 ID。
4. 覆盖总览/菜单完成同步、自动推进、输入校验和无任务结束状态，再执行完整门禁。

## 每个阶段完成定义

- 规格、迁移、实现、测试同步完成。
- 无未声明副作用。
- 关键错误有用户可理解的反馈。
- 验收矩阵更新且自动化用例通过。
