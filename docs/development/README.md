# Life-OS 开发文档索引

本目录是原型冻结后进入正式开发的执行基线。若与早期原型说明冲突，以本目录文档和 `Life-OS_PRD_v3.md` 的最新明确规则为准。

| 文档 | 用途 |
|---|---|
| `00-baseline.md` | 原型冻结范围、目标与非目标 |
| `01-functional-spec.md` | 模块功能、交互状态和业务规则 |
| `02-architecture.md` | 目标技术架构、模块边界和副作用 |
| `03-data-model.md` | SQLite 表、约束、索引和迁移原则 |
| `04-service-contracts.md` | 前端调用的领域服务契约 |
| `05-security-idempotency.md` | 输入安全、权限、幂等与恢复策略 |
| `06-test-plan.md` | 自动化测试、视觉验收和发布门禁 |
| `07-implementation-plan.md` | 分阶段开发顺序和交付物 |
| `08-traceability.md` | 需求到实现、测试的追踪矩阵 |
| `11-p6-desktop-release.md` | P6 桌面能力、可访问性与发布规格 |
| `12-release-checklist.md` | 发布候选构建、签名、公证、安装与视觉验收清单 |

## 文档状态

- 产品原型：已冻结，可作为视觉与交互参考。
- 开发规格：P0–P5 已确认并实现；P6 按子阶段同步规格、实现和测试。
- 正式代码：P0–P5 已完成；P6-A、P6-B1 至 P6-B4、P6-C1 已完成，真实签名与发布环境验收待执行。

## 变更规则

1. 业务规则变化先修改功能规格和追踪矩阵。
2. 数据约束变化同时修改数据模型、迁移和测试计划。
3. 新增副作用必须先写入服务契约。
4. 功能代码、迁移、测试和文档作为一个原子单元提交。
