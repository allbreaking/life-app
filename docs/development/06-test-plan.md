# 测试与发布门禁

## 单元测试

- 四象限与 Top 3 约束。
- 重复生活日程在闰年、月末、双周边界的投影。
- 日历分钟/像素换算和 15 分钟吸附。
- 财务消费进度与时间进度预警。
- 食物到期阈值和跨时区日期边界。
- 投资逐股价格预警。
- 持仓目标价/建仓价、建仓价/安全价的百分比口径、两位小数展示与减半仓成本回到安全价的代数恒等式。
- 新浪行情代码映射、响应解析、无效/重复/超量代码拒绝、北京时间交易窗口、陈旧日期不覆盖及网络失败保留最后价格。
- 学习里程碑派生进度。

## 数据库集成测试

- 外键开启并拒绝孤立持仓。
- EOD 联动事务任一步失败时完整回滚。
- 日复盘同日 upsert 不重复。
- 排期/退回任务池只更新一条 task。
- food 无 expiry_date、item 无 location 时数据库拒绝。
- 每份迁移支持从上一正式 schema 升级。

## 组件测试

- 每个模块存在独立新增入口。
- 快捷录入与模块表单产生相同领域命令。
- 自定义下拉支持鼠标、键盘和焦点恢复。
- 持仓表单不再出现止损价输入；当前持仓不直接展示现价，展示建仓价、浮动盈亏、两项价差，且仅在成本高于安全价时展示减仓价。
- 持仓建仓价可原地编辑；有效值保存后持久化并重算派生指标，无效值被拒绝，取消不修改持久化数据。
- 清仓输入有效正价后计算并保存盈亏百分比，当前持仓与已清仓 Tab 互斥展示；取消不改变持仓状态。
- 每日复盘在原条目内编辑；有效内容保存、取消恢复原文，删除后该日期记录不再展示。
- 学习领域列表进入/退出整页工作区。
- 生活日程只读，普通任务可拖拽和缩放。
- 总览、财务、物品和投资的告警容器使用与告警严重度匹配的共享呼吸动画类。

## E2E 关键路径

1. 创建 Q2 工作任务 → 日程池 → 排期 → 完成 → 工作模块同步。
2. 保存 EOD → 明日任务和收获同时出现。
3. 创建生活模板 → 日/周/月出现 → 模板修改后统一变化。
4. 记录非必要支出 → 月末结算 → 预算预警更新。
5. 添加临期食物 → 总览出现预警。
6. 观察列表建仓 → 非观察标的被拒绝。
7. 创建学习领域 → 进入工作区 → 添加里程碑与任务 → 进度更新。

## 视觉与可访问性

- 1440×900、1024×768、窄屏三档截图回归。
- 键盘可完成导航、表单和自定义下拉。
- 焦点可见；预警不只依赖颜色；动画遵循 reduced-motion。
- 原地编辑输入框在常态和 `focus-visible` 状态均无边框、外轮廓和阴影，聚焦时以背景变化提示。

## 发布门禁

- 类型检查、lint、单元、集成、E2E 全部通过。
- migration dry-run 与外键检查通过。
- 需求追踪矩阵无未覆盖的 P0/P1 项。
- 无高危依赖告警；构建产物完成签名验证。
- `npm run release:verify` 检查入口 JS ≤ 350 KiB、CSS ≤ 25 KiB、HTML/CSS/JS gzip 总量 ≤ 110 KiB。
- npm/Cargo/Tauri 版本一致，CSP、capability、identifier 与 bundle 图标通过静态审计。
- 本机未签名 bundle 只用于安装冒烟；正式发布必须在受控环境完成签名、公证和签名验证。
