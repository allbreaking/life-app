# Life-OS MVP 规格

## 目标

把 `Life-OS_PRD_v3.md` 与 `life_os_prototype.html` 转化为可运行、可持久化的本地优先 Web 应用。MVP 保留九大模块、全局快捷录入、原地编辑和关键约束机制。

## 范围

- 今日总览：展示 Top 3、下一日程、预算与风险预警，可勾选任务。
- 人生地图：Being/Doing 原则与演进日志的新增、原地编辑。
- 工作：四象限任务、Top 3 约束、EOD 提交及历史。
- 日程：日/周/月三种独立布局；待排期池按工作、学习、物品、社交等来源模块分组，不把所有任务混在单一列表中。
- 排期交互：待排期任务可拖入日视图时间段、周视图某天或月视图某日；已排期任务可继续拖动修改日期/时间，也可拖回待排期池清除排期。成功排期后从来源分组移除，目标视图显示来源标签，底层仍引用原任务 ID 而不复制业务实体。
- 工作来源任务在待排期池和已排期卡片上均展示 Q1–Q4 象限。
- 投资模块提供页面内每日复盘录入框；同一天再次提交会更新当天复盘，快捷录入复用相同动作。
- 投资 SOP 支持在当前卡片内原地编辑、保存和取消，并在重启后恢复。
- 日/周视图采用 Apple Calendar 式连续时间画布：事件按分钟位置和时长显示，拖动时按 15 分钟吸附，底部拖柄调整时长，时间输入可精确到任意分钟；当前时间使用横线标识。月视图负责日期级概览。
- 生活日程录入区位于日程页面底部；支持每天、每周、每月、每两周，仅设置开始时间；每周和每两周另选星期，每月另选日期。时间线预览按所选的一天汇总当前所有生活日程，并按开始时间排序，而不是预览单条任务的未来发生次数。
- 生活日程是固定重复模板：在日/周/月视图中只读，不允许拖动、修改时间、调整时长或退回任务池；只能在生活日程管理区修改或删除，变更后各视图重新计算。
- 财务：必要支出即时入账、非必要支出进入月末队列、预算阈值预警。
- 月度预算同时比较消费进度与当月时间进度：消费比例领先时间比例时触发 Amber 卡片呼吸预警，达到预算上限时升级为 Crimson，并显示领先幅度。
- 物品：分类新增与临期/维护信息展示。
- 物品增加存放位置字段。食物作为独立分类，必须完整展示全部条目并记录到期日；过期或 ≤3 天为 Crimson，≤7 天为 Amber，其余正常。修改到期日后即时重算预警。
- 物品模块采用主内容区加右侧新增栏布局；添加物品/资产表单在桌面端固定于右侧，窄屏自动降为单列。
- 学习模块采用主内容区加右侧新增栏布局；学习任务和闪念的关联领域必须从现有学习领域下拉选择，不接受自由文本。
- 学习模块采用“领域列表 → 领域工作区”两级整页结构。领域列表只管理领域；任务、里程碑和基本信息只能在具体领域工作区管理，领域进度由里程碑完成率驱动。
- 社交：人物名片、互动与重要日期。
- 投资：观察列表价格预警、仅从观察列表建仓。
- 投资观察列表新增时从新浪财经读取 A 股最近价格；北京时间交易窗口每 60 秒刷新，失败或陈旧行情保留最后成功价格。
- 学习：领域、待排期任务、闪念与工作收获池。
- 全局：`⌥ Space` 快捷录入、模块导航、本地持久化、重置演示数据。

## 录入与编辑原则

- 每个业务模块必须提供页面内独立新增入口，用户无需打开全局快捷面板即可完成该模块的新增。
- 每个模块的既有用户内容必须能在当前页面原地编辑，不使用 `prompt()` 或跳转编辑页。
- 快捷录入只是一条并行的低摩擦入口，必须复用模块动作与校验规则，不能成为任何模块的唯一新增入口。

## 验收标准

1. 刷新页面后用户新增和编辑的数据仍存在。
2. 所有文本外部输入以文本节点渲染或先转义，不执行 HTML/脚本。
3. 非法金额、空必填项和不合理价格区间会给出页面内错误反馈。
4. 非必要支出不立即占用预算；结余足够时才可月末放行。
5. 持仓标的只能来源于观察列表。
6. 快捷录入提交后数据进入对应模块，而非仅关闭面板。
7. 小屏幕下导航和内容可用，不产生不可访问区域。
8. 关闭快捷面板后，仍可分别在九个模块页面完成该模块的新增和编辑。
9. 日程待排期池按模块分组，拖放在日/周/月视图均有明确落点和视觉反馈。
10. 已排期任务可重新拖放或退回任务池，往返过程中 ID、来源模块和工作象限保持不变。

## 函数副作用约定

- `store.*`：唯一允许读写 `localStorage` 的边界；写入会持久化完整应用状态。
- `render*`：只更新 DOM，不写存储、不发网络请求。
- `add/update/toggle/settle/submit*`：校验输入，修改内存状态，调用持久化并重新渲染。
- `navigate/open/close/toggle*`：仅改变当前 DOM 可见状态与焦点。
- `tickClock`：读取系统时间并更新菜单栏时钟；定时器每 30 秒触发。
- 本 MVP 不发起网络请求，不访问文件系统，不执行用户输入。

## 非目标

- macOS 原生菜单栏、全局系统快捷键、SQLite、系统通知。
- macOS 自定义应用菜单保留系统标准编辑角色，使所有文本输入控件支持剪切、复制、粘贴、全选和撤销/重做快捷键。
- 新浪行情后台轮询、Markdown 文件上传。
- 周/月日历拖拽、云同步、多用户与账号系统。
