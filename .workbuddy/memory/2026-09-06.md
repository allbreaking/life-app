## 修复发布审计 CSS 超限

- 现象：`tests/verify-release.mjs` 报 `CSS 26185 B 超过 25600 B`（`release:audit` 硬上限 25*1024）。
- 原因：最初给 DailyTodoCard 加了 9 条 `.daily-todo-*` 样式；且项目 CSS 本来就濒临上限（工作区有大量进行中的未提交改动）。
- 解法：让 DailyTodoCard 复用现有类（`.todo-row`/`.todo-check`/`.todo-title`/`.watch-row-actions`/`.inline-form`），新增 CSS 归零；仅给 `.todo-check` 补充 `border:0;padding:0` 以重置 button 默认样式（原本是 span，现改为可点击 button）。
- 结果：CSS 从 25614 降到 25592 B，审计通过；但余量仅 8 B，CSS 体积预算已极度紧张，后续加样式建议提高 `verify-release.mjs` 的 css 上限或做一次全局 CSS 瘦身。
