## 今日待办同步 macOS 日历 + 提醒事项（EventKit）

- 用户需求：今日待办卡片同步 macOS 当天日程 + 今天到期/逾期未完成提醒，点按钮同步；用户选了「可勾选完成回写」+「今天到期 + 逾期未完成」。
- 实现：新增 `src-tauri/src/calendar.rs`（`CalendarService` + `sync_today_calendar` / `set_reminder_completed` command）、`src/shared/ipc/calendar.ts`、`src/features/dashboard/TodayAgenda.tsx`；`src-tauri/Info.plist` 声明 `NSCalendarsUsageDescription` + `NSRemindersUsageDescription`。
- 依赖：`[target cfg(macos)]` 加 `block2`、`objc2`、`objc2-event-kit`、`objc2-foundation`（features: NSDate/NSString/NSCalendar/NSArray/NSError）。
- **EventKit 关键坑（objc2 0.6）**：
  - `EKEventStore`/`EKReminder` 非 `Send/Sync`，必须单线程内创建并释放，`CalendarService` 做成无状态（每次调用内 new store）。
  - 权限/查询回调是 block：`requestFullAccessTo…` 参数是 `*mut Block`，要用 `RcBlock::as_ptr(&handler)`；`fetchRemindersMatchingPredicate_completion` 参数是 `&Block`，要用 `&*handler`（两者签名不同！）。
  - `downcast::<EKReminder>()` 返回 `Result`（不是 Option），用 `let Ok(...) = ... else`。
  - `eventIdentifier()` 返回 `Option<Retained<NSString>>`；`startDate/endDate` 返回 `Retained<NSDate>`（取引用用 `&*`）；`dateFromComponents` 返回 `Option<Retained<NSDate>>`；`timeIntervalSince1970`/`currentCalendar`/`dateFromComponents` 是 safe 方法（不用 unsafe）。
  - `EKAuthorizationStatus` 的 `FullAccess` 与废弃的 `Authorized` 值相同（都是 3），match 只用 `FullAccess` 即可。
- 提醒事项 due date 是 `NSDateComponents`（非 NSDate），用 `NSCalendar::dateFromComponents` 转 NSDate 再取时间戳。
- 验证：typecheck + 89 前端测试（新增 calendar.test.ts 4 项）+ cargo test 26 项（含 calendar 序列化测试）+ build + release:audit 通过（JS 363,117 B / 360 KiB 预算内）。**未在真实 macOS 验证权限弹窗与真实日历读写，需用户实机确认**。
- 发布预算现状：JS 360 KiB / CSS 25 KiB / gzip 115 KiB；本次改动后 gzip 114,079 B（余量约 3.6KB，仍紧）。

## 日程完成状态（本地持久化）

- 用户需求：系统日历事件没有"完成"字段，但 Life-OS 希望同步的日程能标记完成。方案：完成状态只存 Life-OS 本地，不回写系统日历。
- 新增领域资源 `dashboard.completedEvents`：对象标量 `{ eventId → 'YYYY-MM-DD' }`，按本地日期判断完成、隔天自动刷新。前端 schema `z.record(z.string(), z.string().regex(date))`。
- **关键坑**：eventIdentifier 含冒号（`UUID:20260919T...`），不能作为数组实体的 `id`（Rust `valid_token` 只允许 `[A-Za-z0-9_-]` ≤100）。所以存**对象标量**（key 走 domain_value，不经过 entity_id 校验），而不是实体数组。
- 资源接入三处：`domain_resource.rs::RESOURCES`、`domainResource.ts::domainResourceSchema`、`demoData.ts::productionDefaults`。
- 验证：typecheck + 89 前端 + 26 Rust + build + release:audit 通过（gzip 114,182 B）。
