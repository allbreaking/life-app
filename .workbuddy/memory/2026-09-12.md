## 移除工作/日程/学习三个模块

按用户要求，从 Life-OS 中移除「工作」「日程」「学习」三个业务模块，剩余六模块：今日总览、人生地图、财务、物品、社交、投资。

用户决策（经 AskUserQuestion 确认）：
- 保留「今日待办」卡片和 macOS 菜单栏状态项作为占位（无数据源）。
- 彻底清理数据链路（资源键、Rust 白名单、demoData 默认值、`sync_menu_bar_todo` 命令及相关测试）。

关键改动：
- 删除 `src/features/{work,schedule,learning}` 三目录、`src/shared/ipc/menuBarTodo.ts`。
- `todayKey()` 从 `scheduleState.ts` 迁移到 `dailyTodos.ts`（被 DailyTodoCard 复用）。
- Rust `desktop_shell.rs` 移除待办投影与 `sync_menu_bar_todo`，托盘改为静态占位（打开快捷录入/回到今日总览）。
- 前端 `domainResource.ts` 与 Rust `domain_resource.rs` RESOURCES 移除 work.*/schedule.*/learning.domains。
- 同步更新 `doc/requirements-current.md`、`doc/feature-entry-map.md`。

验证全绿：typecheck、vitest 63、cargo test 25、build。

注意：`tests/verify.mjs` 校验的是冻结原型 `life_os_prototype.html`（仍 9 模块），未改动；`docs/`、`Life-OS_PRD_v3.md` 等前瞻规格文档也未动，若需同步另行处理。
